Bitmap Lab

Verken de Bitmap-stack via Ordinals recursive endpoints — district = block height, parcel = tx-index, .bitmap = deed (niet het terrein).

Bron: https://0rdinals.com/r/… — rechtstreeks vanuit je browser (die site staat dat toe), zonder eigen server. Alleen lezen: deze pagina tekent of verstuurt nooit iets.

District Bitcoin block height N ↔ Bitmap district N
Parcel Bitcoin tx-index i ↔ Bitmap parcel i.N
Deed (.bitmap) De .bitmap-inscription is het eigendomsakte (deed), niet het terrein zelf.

Deed — .bitmap inscription

        
De inscription met content als {N}.bitmap is de akte. Het terrein (block) bestaat altijd on-chain; de deed is optioneel en wijst ownership aan.

        

          Geen auto-lookup. Ordinals recursive API mapt N niet naar inscription_id.
          Plak hieronder een district-inscription id (uit je eigen OCI/index). Deze lab raadt geen Magic Eden of TRAC aan.
